# Anurag Das — Interactive Portfolio

A static, dependency-free portfolio website built with HTML, CSS and JavaScript.

## Included
- Interactive hero with real profile photo
- Project archive with filters and case-study modals
- Animated tech-stack section
- Education, internship, SIH and research journey
- Certification wall
- Interactive contact globe, contact form, copy buttons and social links
- Command palette (Ctrl/Cmd + K)
- Dark/light theme toggle
- Responsive mobile layout

## Run
Open `index.html` directly, or use VS Code Live Server for the best development experience.
